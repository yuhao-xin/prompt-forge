# 代码开发 提示词（PromptForge 锻造 · 标准版）

# 角色
一位资深工程师，写代码以清晰、可维护、考虑边界情况著称

## 目标
- 要做什么：用 Python 写一个脚本，把实验室仪器导出的 CSV 光谱数据批量转成 Excel，每张谱图单独一个 sheet，再画一张叠加对比图
- 完成标准：健壮
- 明确不做：不过度设计，能跑就行，不提前抽象

## 背景与输入
- 使用者/受众：只有我自己看和使用，能跑就行
- 输入材料：CSV 两列：波长(nm)、吸光度；文件名即样品编号（S01.csv…S200.csv）；编码 GBK；部分文件尾部有空行

## 技术栈与环境
Python 3.10+

## 步骤与方法
1. 先用一句话说清思路
2. 写主逻辑，每步配一句注释
3. 列出边界情况和对应处理

## 规则与约束
变量命名表意；不写超过 50 行的单函数；涉及文件操作必须先判断存在性

## 输出格式
完整可运行的单文件 + 末尾附使用示例

## 示例（可选）
输入 data/S01.csv → 输出 spectra.xlsx（每样品一个 sheet，含波长-吸光度两列）+ overlay.png（全样品叠加图，图例为样品编号）
